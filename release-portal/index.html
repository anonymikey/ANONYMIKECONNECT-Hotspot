Installation & Verification

Verify before running
  1. Download the installer or select your local copy using the button on the left.
  2. Compare the SHA256 checksum shown here with the command-line output.
  3. Run the installer once you have confirmed the checksum and file size.

How to verify a checksum

PowerShell:
Get-FileHash ANONYMIKECONNECTV1.0.exe -Algorithm SHA256

macOS / Linux:
shasum -a 256 ANONYMIKECONNECTV1.0.exe

Manual release metadata

If your CI hasn't published a release.json, you can select an installer and the page will compute SHA256 and size locally for testing.
